# SendScriptWhatsApp

Code to send movie scripts or books on Whatsapp to scammers

## USE

Open the chat you want on WhatsApp Web.

Open the file you want.

Copy all the content (click in raw -> ctrl+a -> ctrl+c)

On WhatsApp Web on the console browser ( ctrl+shift+j )

If Chrome warns about pasting, type `allow pasting` and press Enter first.

Paste the code and press Enter.

Now wait and Enjoy...

## STOP

Type `pararEnvio()` in the console to stop after the current line.

The script also stops by itself if a line can't be sent (e.g. WhatsApp changed its layout).
